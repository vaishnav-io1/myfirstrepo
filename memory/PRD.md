# VM Consultancy Website - PRD

## Problem Statement
Build a modern, responsive corporate website for VM Consultancy — an insurance advisory firm that also operates across business consulting, IT/computer education, and pharmaceutical services.

## Architecture
- **Frontend**: React (CRA) + Tailwind CSS + Shadcn UI + Framer Motion
- **Backend**: FastAPI + MongoDB (exists but forms are currently frontend-only)
- **Single-page scroll**: All sections with smooth scroll navigation

## Core Requirements
- Insurance Advisory as PRIMARY focus (Life, Health, Motor, Home, Travel, Business)
- Consulting, IT Education, Pharma as secondary domains
- Founder: Purnendu Shankar Upadhyay (Chief Insurance Advisor)
- Careers section with job listings
- All forms frontend-only (backend-ready with TODO comments)
